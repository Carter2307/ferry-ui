Type in the search field, or open the Status filter, to change the rows. Open the menu of a row to see its actions.

The example has no router. A click on a link shows a message with the target of the link.

## Design rules

- **The full row opens the record.** `rowLinkProps()` makes the row open the record on a click. The link in the first cell stays the target for the keyboard and for screen readers.
- **One map for the status.** `PROJECT_STATUS` gives a tone and a label to each status. Each `StatusBadge` and each `StatusDot` reads this map.
- **One dialog for all the rows.** The "Delete" item of each row opens the same controlled `ConfirmDialog`.
- **A toast for a quick action.** "Pause" and "Resume" apply immediately. A toast tells the result.
- **The toolbar shows the result count.** The `actions` slot of `ListToolbar` holds the count.

## States

The example has a prop for each state of the list.

| Prop | The page shows |
| --- | --- |
| `loading` | Skeleton rows below the table header. The toolbar is disabled. |
| `error` | An error row with the message of the error. The toolbar is disabled. |
| `onRetry` | A "Retry" button in the error row. |
| `projects={[]}` | An empty state with the "New project" action. |

When the filters find no row, an empty state replaces the table. Its "Clear filters" button brings the rows back.
