The record is an API key that expires soon. Select "Rotate key" or "Revoke key". Then confirm in the dialog. The page shows another state.

The example has no router. A click on a link shows a message with the target of the link.

## Design rules

- **The header tells where the record is.** The `eyebrow` of `PageHeader` holds a `PageBackLink` to the parent list. A small `StatusBadge` shows the status next to the title.
- **A callout for a condition, a toast for a result.** The `Callout` stays on the page while the condition is true. The result of an action is a toast.
- **Tabs change the view, not the page.** The `underline` tabs show the views of the same record. The `pills` tabs change the language of the code sample.
- **A secret stays masked.** `SecretField` hides the value until the user reveals it. A copy does not reveal the value.
- **Each action asks first.** "Rotate key" and "Revoke key" each open a controlled `ConfirmDialog`. The destructive action comes last in the header.

## States

The `status` prop of the example sets the state of the record. The `defaultTab` prop sets the first tab.

| `status` | The page shows |
| --- | --- |
| `active` | A success badge and no callout. |
| `expiring` | A warning badge and a warning callout with a "Rotate now" action. This is the default. |
| `revoked` | A destructive badge and a destructive callout. The page has no secret row. The only action is "Create new key". |
