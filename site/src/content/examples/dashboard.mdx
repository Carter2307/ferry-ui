## The frame

`ExampleApp` is the frame of the four examples. Its source is `src/examples/example-app.tsx`.

- An `AppShell` holds the top bar, the rail and the phone drawer.
- One `NavGroup[]` gives its items to the rail and to the drawer.
- A `ResourceSwitcher` in the top bar changes the workspace.
- The search button opens the command menu. The keys <Kbd>⌘ K</Kbd> or <Kbd>Ctrl K</Kbd> open the same menu.
- A [LinkProvider](/docs/utilities/link-provider) sends each link through one link component.

## Design rules

- **One primary action.** The header has two buttons. Only "New project" has `variant="primary"`.
- **A fact is not a number.** The plan, the owner and the next invoice are `InfoTile`s. The numbers that people compare are `MetricCard`s.
- **A card for a thing with a name.** Each project is a `ResourceCard` with an `href`. The full card is a link.
- **A table for events.** People read the events row by row.
- **A skeleton for each block.** The `loading` prop of the example shows a skeleton in each block. The layout does not move when the data comes.
