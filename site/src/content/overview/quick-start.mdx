## Install the library

libui is one package. It needs React 19.

<PackageTabs packages="libui-kit" />

<Callout tone="info" title="libui is not on npm yet">
  Until the first release, build the package from the repository. The [Installation](/docs/overview/installation) page gives the commands.
</Callout>

Your bundle contains only the components that your app imports.

## Add the styles

Your app uses Tailwind CSS v4? Import the theme of libui after Tailwind.

```css title="app.css"
@import "tailwindcss";
@import "libui-kit/fonts.css"; /* optional: Inter and Source Code Pro */
@import "libui-kit/theme.css";
```

Your app does not use Tailwind? Import the compiled stylesheet at the root of the app.

```ts title="main.tsx"
import 'libui-kit/styles.css'
import 'libui-kit/fonts.css' // optional
```

## Mount the providers

Mount the providers one time, at the root of the app.

```tsx title="providers.tsx"
import type { ReactNode } from 'react'
import { ThemeProvider, Toaster, TooltipProvider } from 'libui-kit'

export function Providers({ children }: { children: ReactNode }) {
  return (
    <ThemeProvider defaultTheme="system">
      <TooltipProvider>
        {children}
        <Toaster />
      </TooltipProvider>
    </ThemeProvider>
  )
}
```

| Provider | Role |
| --- | --- |
| `ThemeProvider` | Applies the light theme or the dark theme. |
| `TooltipProvider` | Gives one delay to all the tooltips. |
| `Toaster` | Shows the messages of `toast()`. |
